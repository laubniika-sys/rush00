# Rush00 - 42 São Paulo

## 📌 About

This project was developed during the 42 São Paulo Piscine, an intensive coding program focused on problem-solving and peer-to-peer learning.

The goal of this project is to generate graphical patterns in the terminal using the C programming language.

## 📌 Sobre

Este projeto foi desenvolvido durante a Piscina da 42 São Paulo, um programa intensivo focado em resolução de problemas e aprendizado colaborativo.

O objetivo do projeto é gerar padrões gráficos no terminal utilizando a linguagem C.
